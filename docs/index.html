01 / Server-Werkzeuge

Die Einrichtung gehört dazu.

Das Dashboard läuft auf 127.0.0.1, der Minecraft-Server auf deinem PC. Kein Hosting-Abo nötig.

01

Modpack rein. Server bereit.

Modrinth-Link einfügen, Version wählen oder eine .mrpack bzw. ein Serverpack-ZIP importieren. Downloads werden per SHA1/SHA512 geprüft; Server-Overrides werden übernommen.

02

Das passende Java finden.

Java 8, 17, 21 und 25 werden erkannt, auch Laufzeiten aus der Modrinth App. Minecraft 1.21.x braucht Java 21, Minecraft 26.x Java 25.

03

Sehen, was gerade läuft.

Spieler, Arbeitsspeicher, Laufzeit und lokale Antwortzeit. Ab Minecraft 1.20.3 kommen Tick-Zeit und geschätzte TPS dazu; die Werte werden alle fünf Sekunden aktualisiert.

04

Konsole, ohne Umweg.

Befehle wie list, say oder whitelist add direkt aus der App senden. Die letzten 180 Zeilen bleiben sichtbar.

05

Einen neuen Server anlegen.

Vanilla und Fabric direkt einrichten; Forge und NeoForge über den offiziellen Installer mit einer konkreten Loader-Version.

02 / Zusammen spielen

Deine Freunde kommen mit.

01

Radmin VPN

Kostenlos. Die App zeigt die VPN-Adresse und prüft die Windows-Firewall.

02

Im selben WLAN

Die lokale Netzwerkadresse erscheint automatisch in der Übersicht.

03

playit-Tunnel

Der signierte Agent ist enthalten und wird aus der App gestartet. Keine Router-Portfreigabe nötig.

04

Minekube Connect

Optional für Fabric: Gate-Proxy und Adresse werden eingerichtet.

Eine Welt. Zwei Rechner.

Mit Syncthing kann ein Freund die Welt übernehmen, während dein PC aus ist.

  1. Auf dem Haupt-PC „Freund einladen“ wählen und den Code teilen.
  2. Der Freund fügt den Code ein und schickt seine Geräte-ID zurück.
  3. Syncthing überträgt die geprüfte Welt verschlüsselt. Nach dem Spielen geht sie zurück.
