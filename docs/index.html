⚡

Minekube Connect

Optional für Fabric: Gate-Proxy und Adresse werden kostenlos eingerichtet.

  1. Gemeinsam hosten: Auf dem Hauptrechner „Freund einladen“ klicken und den Code schicken.
  2. Verbinden: Der Freund fügt den Code ein und schickt seine Geräte-ID zurück.
  3. Übernehmen: Syncthing überträgt den geprüften Weltstand verschlüsselt. Ist dein PC aus, startet dein Freund die Welt – danach geht sie zurück.
